# テニス ダブルス対抗戦 組み合わせ表

**ここから使えます → https://takaakiueno.github.io/tennis_round3/index.html**

## 概要

テニスのダブルスで、AチームとBチームの対抗戦を行うときの組み合わせ表を、全ラウンド分まとめて作るツールです。
このツールは、次の6点がなるべく均等になるように組み合わせを決めます。上にあるものほど優先します。

- 試合数(同じチームの全員がほぼ同じ回数だけ出場する)
- 休みの間隔(同じ人が続けて休まない)
- コート1を使う回数(同じチームの全員がほぼ同じ回数だけコート1に入る)
- ペアを組む相手(同じチームの同じ人とばかり組まない)
- 対戦する相手(相手チームの同じ人とばかり当たらない)
- 使うコート全体(コート1以外も、同じ人が同じコートばかりにならない)

コート1を特に優先しているので、センターコートや観客席に近いコートなど、全員に同じ回数だけ回したいコートをコート1にしてください。

選手は `A1`、`A2`、…、`B1`、`B2`、… のように、チーム名と番号で表します。当日は各チームで番号を割り振って使ってください。

## 使い方

### 1. 条件を入力して「決定」を押す

| 項目 | 入力できる値 | 初期値 |
|---|---|---|
| Aチームの人数 | コート数×2 人以上、40 人以下 | 10 |
| Bチームの人数 | コート数×2 人以上、40 人以下 | 10 |
| 使用コート数 | 1〜6 | 4 |
| ラウンド数 | 1〜100 | 30 |

AチームとBチームの人数差は 2 人以内にしてください。

「決定」を押すと、約12秒で全ラウンド分の組み合わせが表示されます。計算中は「計算中… 29%」のように進み具合が出ます。乱数を使っているので、押すたびに別の案になります。

### 2. 組み合わせ表を見る

1ラウンドが1行です。

<thead>
<tr><th nowrap></th><th nowrap>R</th><th nowrap>コート1</th><th nowrap>コート2</th><th nowrap>休み</th></tr>

<tr><td nowrap>☐</td><td nowrap>1</td><td nowrap>A2&#8288;・&#8288;A7&nbsp;-&nbsp;B3&#8288;・&#8288;B4</td><td nowrap>A4&#8288;・&#8288;A5&nbsp;-&nbsp;B1&#8288;・&#8288;B2</td><td nowrap>A1,&nbsp;A3,&nbsp;A6,&nbsp;B5,&nbsp;B6</td></tr>
<tr><td nowrap>☐</td><td nowrap>2</td><td nowrap>A1&#8288;・&#8288;A6&nbsp;-&nbsp;B1&#8288;・&#8288;B6</td><td nowrap>A3&#8288;・&#8288;A4&nbsp;-&nbsp;B3&#8288;・&#8288;B5</td><td nowrap>A2,&nbsp;A5,&nbsp;A7,&nbsp;B2,&nbsp;B4</td></tr>
</tbody>
</table>

- `A2・A7 - B3・B4` は「A2 と A7 のペア」対「B3 と B4 のペア」の試合です。左がAチーム、右がBチームです。
- 画面では、Aチームの選手を青、Bチームの選手を橙で色分けしています。
- 「休み」は、そのラウンドに出場しない人です。全ラウンドで休みの人がいないときは、この列は出ません。
- 左端のチェックボックスは、終わったラウンドの目印です。チェックを入れると、その行の文字が薄くなります。
- 「csv出力」ボタンを押すと、組み合わせを CSV ファイルとして保存できます(下の「CSV 出力」を参照)。

チェックが1つでも入った状態で「決定」を押すと、作り直してよいかの確認が出ます。キャンセルすれば今の表が残ります。

### 3. CSV 出力

「csv出力」ボタンを押すと、`tennis_taikousen.csv` というファイルがダウンロードされます。Excel などの表計算ソフトで開けます。

中身はコートごとにまとめてあります。まず「コート1」という行があり、その下に第1ラウンドから順に1ラウンド1行で、そのコートの試合の4人が並びます。続けて「コート2」以降が同じ形で並びます。最後のコートの下には「休み」という行があり、その下に1ラウンド1行で、そのラウンドに休む人が並びます。

```
コート1
2,3,,2,3
1,4,,5,6
6,7,,7,8
コート2
5,8,,1,4
3,7,,2,8
1,2,,3,5
休み
A1,A4,A6,A7,B5,B6,B7,B8
A2,A5,A6,A8,B1,B3,B4,B7
A3,A4,A5,A8,B1,B2,B4,B6
```

- コートの各行は、「A」「B」を付けず番号だけを出力します。空のセルを1つ挟んで、左がAチームのペア、右がBチームのペアです(`Aチームの2人,(空),Bチームの2人`)。上の例の `2,3,,2,3` は「A2 と A3 のペア」対「B2 と B3 のペア」です。
- 行の順番がラウンドの順番です。各コートの1行目が第1ラウンド、2行目が第2ラウンドです。
- 「休み」の各行は、`A1`、`B5` のように「A」「B」を付けて出力します。Aチームの人、Bチームの人の順に番号順で並び、間に空のセルは入りません。全ラウンドでだれも休まない場合、「休み」の部分は出力されません。
- チェックの状態は出力されません。

### 4. 偏りを確認する

表の下の「偏りのチェック」欄で、どのくらい均等に組めたかを確認できます。

最初の5行は、回数ごとの分布です。

- **コート1を使う回数**: チームごとに、コート1で試合をする回数別の人数を示します。`Aチーム 6回: 10人 | Bチーム 6回: 8人 / 7回: 2人` なら、「Aチームは全員6回、Bチームは6回が8人と7回が2人」という意味です。チーム内の回数の差は、ふつう1以内に収まります。
- **Aチーム内で同じ人とペアを組んだ回数**: Aチームの2人の組み合わせすべてについて、ペアを組んだ回数ごとに何組あるかを示します。`0回: 13組 / 1回: 32組` なら、「一度も組まない2人が13組、1回だけ組む2人が32組あり、2回以上組む2人はいない」という意味です。
- **Bチーム内で同じ人とペアを組んだ回数**: 同じ見方で、Bチームの分です。
- **相手チームの同じ人と対戦した回数**: Aの1人とBの1人の組み合わせすべてについて、対戦した回数ごとに何組あるかを示します。
- **コートの偏り**: 各人について、いちばん多く使うコートと、いちばん少なく使うコートの回数の差を出し、その差ごとに何人いるかを示します。`差0: 18人 / 差2: 2人` なら、「18人はどのコートも同じ回数で、2人は最多と最少で2回の差がある」という意味です。

どの行も、数字の幅が狭いほど(コートの偏りは差が小さいほど)均等です。「コートの偏り」は、コート1を含むすべてのコートについての値です。

その下に、チームごとの表があります。横に選手が並び、縦に次の項目が並びます。

| 行 | 内容 |
|---|---|
| 試合数 | その人が出場する回数 |
| 休み | その人が休む回数 |
| 連続休み(最大) | 続けて休む回数の最大。1 なら、2回続けて休むことはありません。 |
| コート1、コート2、… | その人がそのコートで試合をする回数 |

人数が違うチームどうしでは、人数が少ないチームのほうが、1人あたりの試合数が多くなります。

### 5. 全員分の内訳表を見る

いちばん下の「全員分の内訳表(ペア回数 / 対戦回数)」には、2人の組み合わせごとの回数をすべて並べた表が3つあります。

- **Aチーム内のペア回数**: 縦と横にAチームの選手が並び、交わるマスが、その2人がペアを組む回数です。
- **Bチーム内のペア回数**: 同じ見方で、Bチームの分です。
- **対戦回数**: 縦にAチーム、横にBチームの選手が並び、交わるマスが、その2人が相手として対戦する回数です。

ペア回数の表は、たとえば次のように読みます。

| | A1 | A2 | A3 |
|---|---|---|---|
| **A1** | | 1 | 0 |
| **A2** | 1 | | 2 |
| **A3** | 0 | 2 | |

この例では、A1 と A2 は1回ペアを組み、A1 と A3 は一度も組まず、A2 と A3 は2回組みます。同じ選手どうしのマス(斜めの線上)は空欄です。表は斜めの線を挟んで対称なので、どちらの選手から引いても同じ値になります。

特定の2人の関係を調べたいときや、偏りが出ている組み合わせを探したいときに使ってください。

## データの保存について

組み合わせとチェックの状態は、使っているブラウザの中に自動で保存されます。ページを再読み込みしたり、閉じて開き直したりしても、前回の入力値と表がそのまま表示されます。

- **保存のタイミング**: 「決定」で組み合わせを作ったときと、チェックを付け外ししたときです。
- **保存先**: ブラウザ内(localStorage)だけです。入力した内容や組み合わせがサーバーに送られることはありません。
- **共有されない**: 保存は端末ごと・ブラウザごとです。他の人の端末や、自分の別の端末・別のブラウザには引き継がれません。全員で同じ表を見るには、1人が作った表を画面で見せるか、CSV ファイルやスクリーンショットで配ってください。
- **消える場合**: シークレットウィンドウ(プライベートブラウズ)で使った場合や、ブラウザの閲覧データを消去した場合は残りません。
- **保存できる表は1つ**: 新しく「決定」を押して作り直すと、前の表は上書きされます。

## アルゴリズム

### 評価値

「均等さ」を1つの数値で測り、それが小さくなる計画を探します。

```
評価値 = 1000 × Σ(各人がコート1を使った回数)²
       +    3 × Σ(ペアを組んだ回数)²
       +    1 × Σ(対戦した回数)²
       +    2 × Σ(各人が各コートを使った回数)²
```

1行目は選手全員、2行目は同じチームの2人の組み合わせすべて、3行目はAの1人とBの1人の組み合わせすべて、4行目は選手とコートの組み合わせすべて(コート1も含む)についての合計です。

- **2乗する理由**: 回数が一部に集中するほど値が大きくなります。たとえば「ある2人が2回、別の2人が0回」は 4+0=4、「どちらも1回ずつ」は 1+1=2 となり、ばらけているほうが良いと判定されます。コートも同じで、「コート1を4回、コート2を0回」より「2回ずつ」のほうが値が小さくなります。
- **コート1の重みを1000にする理由**: コート1の均等さを、ペアや対戦相手のばらつきより必ず優先させるためです。他の項をどれだけ良くしても、コート1の偏りが1つ増える損を埋められない大きさにしてあります。
- **残りの重みの違い**: 同じ人と何度も組むことがいちばん目立つので、ペアの重みを対戦やコート全体より大きくしています。

試合数と休みの間隔は評価値には入れず、次の手順1の出場者の選び方で直接そろえます。評価値で調整するのはその後なので、優先順位は「試合数・休み → コート1 → ペア → 対戦・コート全体」になります。

コート1の均等さは、各ラウンドでどの試合をコート1に入れるかを選ぶだけでほぼ達成できます。試合の中身(だれとだれが組み、だれと当たるか)は変えずに済むので、ペアや対戦のばらつきはほとんど損なわれません。

完全に均等な組み合わせは、人数とラウンド数によっては存在しません。そのため、厳密な最適解ではなく、短時間で見つかる範囲でなるべく良い案を採用します。

### 手順

**1. 1ラウンドずつ順に組む**

各ラウンドについて、次の2段階で決めます。

1. 出場者を選ぶ(チームごとにコート数×2 人)。試合数が少ない人を優先します。同数の場合の決め方は、チームの人数によって変わります。
   - 休む人数が出場人数以下のチーム: 前のラウンドで休んだ人を必ず出します。これで連続休みは出ません。残りの枠は乱数で決めるので、毎回ちがう顔ぶれになりやすくなります。
   - 休む人数のほうが多いチーム: 連続休みは避けられないので、最後に出場してから長く休んでいる人から順に出します。
2. 出場者をコートとペアに分ける。まず適当に並べ、次の3種類の入れ替えのうち評価値が下がるものを、下がるものがなくなるまで繰り返します。
   - 同じチームの2人を、別々のコートの間で入れ替える(ペアと対戦相手が変わる)
   - 2つの試合のコートを入れ替える(使うコートだけが変わる)
   - 2つのコートの間でBチームのペアを入れ替える(対戦相手が変わる)

**2. 何度もやり直して最良の案を選ぶ**

1回の結果は乱数次第でばらつきます。そこで、約6秒の間、最初から組み直すことを繰り返し、評価値が最も小さい案を残します。試せる回数は条件や端末の速さによって変わり、初期値(10人対10人・4面・30ラウンド)なら2,000回前後です。

**3. 全体を通した入れ替えで仕上げる(局所探索)**

残した案に対して、さらに約6秒の間、無作為に選んだラウンドで上の3種類の入れ替えのどれかを試し、評価値が悪くならなければ採用することを繰り返します。手順1では各ラウンドをそれまでのラウンドだけを見て決めますが、ここでは全ラウンドを通した評価値で見直します。

入れ替えは同じラウンドの出場者どうしに限るので、だれがどのラウンドに出場するか(試合数と休みの配分)は変わりません。

計算は合わせて約12秒かかります。その間も画面が固まらないよう、短い区切りごとに進み具合の表示を更新しています。

### 顔ぶれが固定される場合

チームの人数がちょうど「コート数×4」人のとき(2面で8人、3面で12人など)は、毎ラウンドそのチームの半数が休みます。「続けて休まない」を守ると、休んだ半数が次のラウンドに必ず出ることになるので、同じ半数どうしが交互に出場し続けます。

この場合、そのチームの残り半分の人とは一度もペアを組みません。両チームともこの人数のときは、相手チームの半分とも一度も当たりません。これは優先順位(休みの間隔を、ペアや対戦相手のばらつきより優先する)に従った結果です。避けたい場合は、人数かコート数を1つ変えてください。
